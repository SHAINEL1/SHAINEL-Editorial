# SHAINEL Editorial · Issue 001

**كابكوم ليست Resident Evil فقط** — مقال عربي تفاعلي مستقل، مبني من ملفات الصور والموسيقى التي قدمها صاحب المشروع.

## معاينة محلية

1. فك الضغط عن الملف كاملًا (لا تنقل `index.html` وحده).
2. افتح `index.html` في متصفح حديث. للمعاينة الأفضل، افتح المجلد عبر خادم محلي مثل `python -m http.server 8000` ثم زُر `http://localhost:8000`.
3. الموسيقى لا تبدأ تلقائيًا؛ اختر «تشغيل أجواء القراءة» أو زر الصوت في أعلى الصفحة.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا في GitHub، مثل `shainel-editorial`.
2. ارفع **محتويات هذا المجلد** إلى جذر المستودع، مع المحافظة على بنية `assets/images/` و `assets/audio/`.
3. ادخل إلى **Settings → Pages**، ثم اختر **Deploy from a branch**، وحدد `main` و`/(root)` ثم Save.
4. رابط الموقع يصبح عادةً `https://YOUR-USERNAME.github.io/shainel-editorial/` بعد اكتمال النشر. استبدل `YOUR-USERNAME` باسم حسابك الحقيقي.
5. زر «مشاركة المقال على X» سيتضمن رابط الصفحة تلقائيًا بعد النشر. قبل النشر، سينسخ نص التغريدة فقط.

## إدارة الموقع

- `index.html` — المحتوى العربي، البنية، وروابط المصادر.
- `styles.css` — الهوية البصرية، حركات الظهور، تصميم الكمبيوتر والجوال، ووضع التصوير.
- `script.js` — شريط تقدم القراءة، الفلاتر، مشغل الصوت، والمشاركة.
- `assets/images/` — أغلفة وشعارات مضغوطة بصيغة WebP.
- `assets/audio/serenity.mp3` — الموسيقى التي رفعتها إلى المحادثة.
- `assets/icons/shainel-mark.svg` — رمز SHAINEL الصغير.
- `assets/icons/shainel-emblem.svg` — رمز SHAINEL الموسّع مع رموز PlayStation وXbox وNintendo وPC.
- `assets/images/social-card.webp` — صورة مشاركة مصممة خصوصًا لمنصات التواصل.

## الاستخدام

- **وضع التصوير:** اضغط أيقونة الكاميرا في الشريط العلوي لتختفي الأدوات العائمة وتصبح الصفحة مناسبة للالتقاط، ثم اضغطها مجددًا بعد إعادة التحميل أو إلغاء الوضع (يمكن أيضًا الضغط على Esc أو تحديث الصفحة للعودة للوضع الطبيعي).
- **الألعاب:** اختر تصنيفًا من المعرض لعرض ألعاب محددة.
- **المصادر:** ستجد المراجع القابلة للنقر في ذيل المقال.
- **الموسيقى:** الصوت الافتراضي 16% (نسبة من مستوى الصوت الكلي داخل الصفحة)، ويمكن تغييره من 0 إلى 35%. يبدأ فقط بالنقر امتثالًا لتفضيلات المتصفح وتجربة القراءة.

## ملاحظات قانونية وتقنية

- الأغلفة والشعارات علامات ومواد محمية تخص أصحابها. هذا مشروع تعليق نقدي مستقل، وليس موقعًا رسميًا لكابكوم.
- **لا تنشر ملف الموسيقى على GitHub Pages إلا إذا كان لديك تصريح/ترخيص مناسب لإعادة نشرها علنًا.** إذا لم يكن ذلك متاحًا، احذف `assets/audio/serenity.mp3` وعطّل المشغل أو استبدله بمقطع مرخّص.
- تتطلب خطوط Google Fonts اتصالًا بالإنترنت للحصول على الخط المفضل؛ يوجد خط بديل محلي في حال عدم التوفر.
- زر الموسيقى يعمل بعد تفاعل المستخدم، ولا توجد أدوات تتبع أو واجهات خلفية.
